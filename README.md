# 창가 한 자리

> 기차 안에서 창밖을 바라보며 잠시 쉬어 가는 3D 웹게임

[게임하기](https://eomtaejun.github.io/window_seat/) · [로컬 실행 안내](DEVELOPMENT.md)

## 01. 무엇을 만들고, 누가 사용하나요?

남는 시간에 간편하게 힐링을 느끼고 싶은 사람이 기차 창밖 풍경을 감상하는 웹게임입니다. 운전하거나 목적지에 도착하는 대신, 여행하는 동안의 분위기에 집중합니다.

## 02. 사용자는 무엇을 할 수 있나요?

1. **여행 설정:** 날씨, 시간대, 풍경과 소리 크기를 선택합니다. 선택한 내용은 창밖 풍경과 환경음에 바로 반영됩니다.
2. **객실 이동:** `W A S D`로 넓어진 복도를 걷고 `Space`로 점프합니다. 클래식, 모던, 카페, 전망 칸을 차례로 둘러볼 수 있습니다.
3. **창가에 앉기:** `F`를 눌러 창가에 앉아 풍경을 가까이서 감상하고, 다시 `F`를 눌러 일어납니다. 마우스로 둘러볼 수 있습니다.
4. **칸 이동:** 연결문 앞에서 `E`로 문을 열거나 닫습니다. 문 위의 이름표로 다음 칸의 콘셉트를 확인합니다.
5. **소리:** 여행 시작 시 기차 주행음과 환경음이 재생됩니다. 화면 상단의 ♫ 버튼으로 끄거나 켜고, 설정에서 소리 크기를 조절할 수 있습니다.

**핵심 기능 확인 방법:** 좌우 창가에 각각 앉아 창밖을 바라보고, 문을 열어 네 칸을 이동합니다. 비, 눈, 낮, 밤, 숲길, 바닷길을 바꾸며 풍경과 소리의 변화를 확인합니다.

## 03. 처음 사용하는 순서

`게임 열기 → 여행 시작하기 → 객실 걷기 → E로 연결문 열기 → F로 창가에 앉기 → 설정에서 여행 분위기 바꾸기 → 창밖 감상하기`

## 04. 이번 범위와 이후 계획

**이번 데모:** 웹에서 실행되는 네 가지 3D 객실, 연결문, 좌우 착석, 실시간 여행 설정, 기차와 자연 환경음, 움직이는 풍경을 구현합니다. 객실과 풍경의 스타일라이즈드 3D 모델도 포함합니다.

**이후 계획:** 더 다양한 지역, 정교한 텍스처와 애니메이션, 역 승하차 등으로 여행 경험을 넓힙니다.

## 05. 현재 상태

Three.js 기반 데모가 구현되어 있습니다. 네 가지 객실·좌석·나무·집·전봇대·역 소품은 프로젝트 안의 GLB 모델로 포함했고, 지형·철도·하늘·안개·날씨와 사운드는 게임에서 생성합니다. 바깥 풍경은 청크를 반복 재사용하고 나무와 풀은 인스턴싱하여 배치합니다. 이 README는 원래 기획서의 실제 기획 내용을 정리하고 구현 현황을 반영했습니다.

## 06. AI 활용과 내 선택

웹에서 Slow Roads 같은 공간감 있는 3D를 구현할 때 성능을 고려해 WebGL/Three.js 사용을 검토했습니다. 짧게 감상할 수 있는 웹게임의 접근성을 유지하면서, 풍경 속을 이동하는 느낌을 살리기 위해 3D 웹 방식을 선택했습니다. AI는 구현과 모델 생성에 도움을 주었고, **운전 대신 기차 여행을 감상하는 게임**이라는 방향은 기획자가 정했습니다.
